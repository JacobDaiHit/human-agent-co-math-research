# Agent 与 DeepSeek 实验记录说明

更新日期：2026-10-02。原方案中的自动短答案评分、按分数比较、强制方框格式与固定研究/审查流程已经退役。此文不授权或启动付费运行，不再提供已删除评分工具的命令。

## 比较的对象

保留三个无标准答案参与的可选基线：裸模型单次回答、固定多轮自查、彼此独立的采样。主研究流程可以连续计算、查阅材料、调整局部任务和邀请同伴，不要求经过统一审查或按人数投票。

独立采样基线仍可按相同短答案选择样本。这只是预先固定的实验选择方法，不能判断数学正确性，也不能用于审查主研究者的证明。只有证明而没有独立短答案的研究提交仍正常保存。

## 记录什么，不判断什么

新报告分别记录运行终止原因、研究者声明已解决或未解决、完整提交正文、可选短答案，以及全部成员的请求、输入、输出、缓存和耗时。缺失用量不是零；缓存命中率按已报告缓存输入数量加权，并报告缺失请求数量。人工干预、结果不明和追加调用单独记录。

程序不根据参考答案、方框数量、关键词、同伴意见一致或所谓“审查通过”认定数学正确。自动评分工具、分数比较工具及其专用测试已删除。冻结的旧报告保持原样，不追改旧成绩，也不把旧完成字段当作当前定义。原始题面和独立答案键仍保留，答案键不进入求解器。

## 公平比较的边界

- 固定题目、原题来源、模型、思考设置、工具权限、费用范围与源码版本；每次使用新目录和独立数据库。曾用于调试和提示改进的题属于开发题，不能假称未见过的确认实验。
- 输入、输出和缓存分别报告；相同输出上限不等于相同费用或总计算量。所有同伴和恢复调用计入整题账本，结果不明的请求保留占用。
- 不挑选有利样本、不利用标准答案挑候选、不把不同模型或参数的运行拼成成功率。传输失败、额度耗尽、未解决与人工干预如实保留。
- 若后来要讨论证明能力，应检查实际证明中的数学推导，可由人或真正的形式化证明系统判断；当前没有实现后者。模型寻找反例或补充论证是数学研究，不是认证。
- 缓存结构的免费检查比较实际发送的旧消息、思考和工具内容是否保持原样；真实服务端命中率只能由获准付费运行的提供方数据确认，不能从本地比较推算保证值。

后续付费测试须另行确认题目、次数和费用范围。当前可用运行示例见 [项目说明](../README.md)，历史失败和实测账目集中在 [测试记录](../docs/testing-history.md)，不新增重复的评分与验收文档。
