# MathAgent

本地数学研究工作台。主研究者可以持续推导、读取材料和使用计算结果，按需要邀请有名字的同伴。程序负责保存、计算、调度和记账，不认证自然语言数学证明。默认使用模拟模型，不产生真实模型费用。

历史问题、旧试验用量和本轮验证集中在 [测试与失败记录](docs/testing-history.md)。当前架构以下文为准；早期施工方案是历史设计，不代表当前求解流程。

## 当前架构

1. **持续研究。** 模型可以直接研究整道题，也可以安排真正困难的局部问题。工具结果返回同一研究过程，读材料或算一次不会重新派发整题。普通正文保存后可以继续，只有显式提交、结束局部任务或等待消息才改变工作状态。
2. **工作稿与完整材料。** 每位研究者有个人工作稿，主研究者维护公共工作稿。长推导、计算和文献另存，模型可查目录并读回全文；模型自己选择何时整理工作稿、缩短对话。历史不被删除，同一原题可接续研究，不跨不同题目自动混用。
3. **按需选择独立探索或针对性合作。** 独立探索可以研究原题或中性的局部问题，形成自己的推导前不看到其他成员的结论。针对性合作则直接接收指定问题和已有材料，不要求先重做完整题。成员持续存在，之后可互相提问、交换反例和失败原因；没有投票或审批门槛。已交流的同伴不会因为重开对话就恢复独立性。
4. **真实数学计算。** 显式启用后，在离线隔离容器中运行 Python 和 SymPy。短计算立即返回，长计算可以后台运行，稍后取结果；工作台在计算期间仍可保存材料。准备方法见 [沙箱说明](sandbox/README.md)。
5. **研究文献。** 普通研究可选择检索和读取 arXiv 原文，保存后再使用；不宣称能覆盖所有数学文献。闭卷评测明确关闭这些工具。
6. **一份共享资源账本。** 所有成员共用整题请求和输出额度。实际用量结算后释放未用预留；暂时被其他请求占满时等待，而不是提前停止整题。费用不明的请求保留占用，不假装没花钱。

没有固定路线数、推进轮数、起步规划小额度、必经审查或固定收尾调用。工具参数只检查能否执行，版本、归属和记录由后台维护。工作台仍有人工证据、采用、分支、批注和导出功能，它们不妨碍模型研究。

旧自主流程停止派发，仅保留历史读取；接续研究请新建当前流程的任务，不会重放旧付费调用。

当前局部任务和当前对话分别保存。换目标、更新笔记、成员加入、额度变化、等待后恢复或人工暂停后恢复，通常继续原对话：开场、系统说明、已有思考、工具请求原文和工具回执不重写，新信息追加在后面。旧回执仍指向当时读到的内容，读取更新后的工作稿会产生新的回执。只有研究者主动整理、信息范围或工具设置改变、接近已知提供方容量等情况，才建立接续对话；完整材料不删除，不额外召集模型做摘要。没有固定十万词元整理线；容量附近的新增输入采用保守粗估，不是精确分词计数。

用量与缓存沿用已有请求账本、运行页和报告，按全部成员合计，并提供成员和对话明细。缓存数据未返回时显示“未提供”，不按零统计；命中率按已报告输入量加权，同时列出缺失数量。旧输入是否原样保留是本地接续事实，不是服务端缓存命中的保证，也不参与决定证明是否成立。

## 启动

需要 Python 3.13、Node.js 20.19+ 或兼容的较新版本。在项目根目录运行 PowerShell：

```powershell
.\scripts\bootstrap.ps1
.\scripts\dev.ps1
```

打开 [本地工作台](http://127.0.0.1:8000)。启动脚本构建网页、启动本地服务和默认四个并发执行槽的模拟 worker；Ctrl+C 只停止脚本启动的进程。`-SkipBuild` 复用网页构建，`-NoWorker` 只打开人工工作台，`-Port 8001` 换端口。

依赖固定在 `uv.lock` 和 `apps/web/package-lock.json`；研究数据在 `data/mathagent.db`，服务日志在 `data/logs/<端口>/`。首次启动自动迁移数据库并生成独立用户与 worker 令牌。网页使用本机会话，密钥和数据库不提交到 Git，不放入模型研究正文。

## 研究与运行设置

新建项目并保存原题，添加必要定义或上下文，然后启动研究。在运行页查看当前任务、每人工作稿、话题讨论、完整产物和请求账本；可以暂停、停止、改方向或调整额度。原题或定义在运行中被改动时，旧回答仍保存，但不混入新版研究。

默认整题请求上限 1,000，单次输出上限 131,072，单次请求最多 3,600 秒，研究时限 86,400 秒，团队人数上限 4（含主研究者）。默认不设置累计输出上限；这些是可调整的资源设置，不是题目难度判断，也不要求用满。单次输出最多可设为 393,216，研究时限最多七天，团队最多 16 人；实际能力还受所选提供方限制。

累计输出按提供方的 token 计量，包含提供方计入输出的思考，所有成员共享。输入另外计费；请求数和输出上限都不是人民币费用硬上限。原有项目与分支的自定义额度不会自动提高，开始长研究前应检查各级余额。

数学正文支持 Markdown 与 LaTeX：行内 `$...$`、独立公式 `$$...$$`，也支持 `\(...\)` 和 `\[...\]`。公式显示方式不决定研究是否完成。图与工作稿支持不可变版本、分支、冲突处理、批注和固定快照导出；“人工采用”不等于证明已获认证。

## 真实模型

自动测试不调用付费模型。复制 `.env.example` 为 `.env`，在本机填写账户配置，再启动对应 worker：

```dotenv
MATHAGENT_DEEPSEEK_API_KEY=<本机填写>
MATHAGENT_DEEPSEEK_MODEL=<账户支持的模型名称>
MATHAGENT_ENABLE_REAL_API=1
```

```powershell
.\scripts\dev.ps1 -Providers fake,deepseek
```

还需要在当前项目的运行设置里允许真实提供方，并确认项目、分支与任务额度。已有进程环境变量优先于 `.env`；修改配置后重启。要跳过文件加载，设 `MATHAGENT_LOAD_ENV=0`。GLM 对应 `MATHAGENT_GLM_API_KEY`、`MATHAGENT_GLM_MODEL` 和 `-Providers fake,glm`，本轮未用其真实账户验证。

默认服务地址为 `https://api.deepseek.com` 和 `https://open.bigmodel.cn/api/paas/v4`。记录实际模型、参数、用量、原始响应和截断情况。结果不明默认停止待对账；只有显式选择“一次续试”才在原额度内追加一笔，原请求不会退回费用。

已知官方模型按其提供方容量安排接续；未知模型或第三方服务不猜测容量。需要时，可在 worker 环境中配置 `MATHAGENT_DEEPSEEK_CONTEXT_CAPACITY` 或 `MATHAGENT_GLM_CONTEXT_CAPACITY`，单位是提供方词元。这是单次输入加生成的物理容量，不是整题累计研究额度。

## 闭卷数论重测

下面的示例未带 `--execute`，程序会提示并退出，不发起模型请求；明确授权费用后再加该选项。每轮必须使用新的输出目录，不能覆盖已有冻结记录。示例团队最多四人，共享一百万输出 token，包含思考；不自动追加批次。文献工具、答案键、旧数学进展和人工解题提示不进入求解器：

```powershell
$env:MATHAGENT_SANDBOX_IMAGE = (docker image inspect --format '{{.Id}}' mathagent-python-sandbox:research-v2).Trim()
.\.venv\Scripts\python.exe -X utf8 scripts\imo_answerbench.py --output data\benchmarks\number-theory-new-run --case-id imo-bench-number_theory-081 --parallel-cases 1 --code-sandbox --max-researchers 4 --request-budget 1000 --max-output-tokens 393216 --request-timeout 3600 --case-timeout 86400 --effort max --unknown-recovery stop --cumulative-output-token-budget 1000000
```

每轮冻结原题、源码和参数，只记录运行状态、研究者声明、提交正文、可选短答案、实际用量、缓存和耗时，不进行自动数学评分。只有证明而没有单独短答案也可以正常交付；“研究者声明已解决”不代表程序认证。旧冻结报告不改写，独立答案键不删除、不送入求解器。多次试验参数变化或模型更新时不能拼成同配置成功率；一题成功也不能证明前沿研究能力。

保留裸模型单次、自查和独立采样的可选试验入口；独立采样中的相同短答案选择只是该基线的实验策略，不是数学裁判，也不进入主研究流程。相关比较边界见 [实验记录说明](施工方案/Agent与DeepSeek公平对照评测_2026-09-13.md)。

备份可以在服务运行期间执行，包含研究正文与引用的固定计算材料，不包含会话令牌；输出文件不能已存在。恢复目录必须是新的或空目录，活动运行恢复为中断，不自动调用模型。

[接口文档](http://127.0.0.1:8000/docs) 中，用户与 worker 使用独立令牌。写操作带幂等标识，正文更新带明确的旧版本；这些保证保存和运行一致，不判断数学真伪。Python 安装包包含服务与 worker；独立安装网页时需构建前端并设置 `MATHAGENT_FRONTEND_DIST`。
