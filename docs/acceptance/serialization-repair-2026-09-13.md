# 序列化恢复改进

针对 run11 的未转义双引号和操作列表分隔错误，提示版本更新为 `research-operations-v12`。

- JSON 解析错误反馈包含行、列、偏移和最多 160 字符附近片段，不再仅提供泛化的“无效 JSON”。
- 格式恢复使用独立序列化系统指令，替换原始解题指令，保留预算、输入证据和操作 schema 供校验；不重新推导、不升级结论、不声称操作已执行。
- DeepSeek 格式恢复关闭长推理，effort 使用兼容的 provider_default；清除与格式恢复混用的长度恢复提示。长度恢复仍是缩小数学子目标的另一路径。
- 不自动猜测替换正文引号或删除操作列表括号。不修改原始响应、失败记账或数学结论。修复仍须通过 JSON、角色、引用及操作约束并占用原预算。
