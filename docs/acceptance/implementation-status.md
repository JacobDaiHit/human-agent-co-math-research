## 本次审计发现并补齐的导出缺口

原研究导出只保存 RunOptions 和 ProviderRequest，未包含新加入的 AgentRun、AgentStep、ProviderCall 与 BranchRuntime。现已在 [导出服务](../../services/api/src/mathagent/exports/service.py) 补齐，并由 [跨分支代理导出测试](../../tests/integration/test_agent_export.py) 实际验证：

- `snapshot.runs` 的 `agent`、`steps`、`provider_calls` 保存父子关系、每步动作/回执、调用配置、原文/哈希、截断/完整性、结果和用量；相关任务族可跨分支，其他分支不相关 Run 不混入。
- `snapshot.runtime_branches` 保存相关分支的控制/预算状态；相关子任务事件也进入事件快照。
- 版本闭包覆盖所有尝试的 read_set/context_revision_ids、审查目标、实际读/检索结果、步骤和子任务输出，以及既有证明/Review/失败引用。被拒绝模型动作中的任意 ID 不升级为真实依赖。
- 研究→子研究→独立审查→修订后，旧目标、新版本、5 次调用、4 个研究步骤均可导出。Attempt.token 及嵌套凭据字段被剔除；以后修改分支设置不改变已创建 ZIP。
- 文件产物创建 export 时校验并冻结到回执，ZIP 包含独立文件及 manifest 校验值。源文件后来缺失不会改变已创建的导出；新导出遇到缺失/篡改会明确失败。
