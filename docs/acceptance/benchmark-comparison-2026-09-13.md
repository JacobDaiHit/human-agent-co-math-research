# 评测分层与公平对照实现验收

本轮仅修改代码、文档并进行本地合成推理测试；没有新增真实 DeepSeek 请求，没有修改 run01 至 run06、历史成绩、答案键或 `.env`。

## 已实现

- `--evaluation-mode answer|research`：默认仍为 research。答案模式允许明确提交带证明缺口的答案，不产生“定理已证明/已采用”状态。新报告独立保存提交回执、最后步骤候选、相关固定版本的内部审查状态、工作流状态和 token 汇总；历史版本的失败审查不会污染新版本状态。
- 回执选择规则在 `plan.json` 冻结：只取最后一个有效根步骤明确 finish 的单一盒装答案；不从早期猜测、子任务或标准答案中挑值。基线只取最后完整响应中的单一盒装答案。
- 本地评分器 v3 对 schema-v2 的正式提交独立评分；没有提交仍为缺答。旧格式报告保留旧完成门槛，不自动将旧草稿改成答案；写入仍禁止覆盖既有评分文件。该评分器不是官方 AnswerAutoGrader，完整题库评分覆盖仍需核验。
- `--solver direct|self_refine|agent`：单次自然语言基线、固定多轮自然语言自查基线和完整 agent。裸基线没有研究操作 JSON、计算或联网工具，不宣称完成证明审查。自查总采用最后一轮，不做答案键辅助选择；未知回执保留额度，目录不能自动重复使用，不支持裸基线 resume。
- `--no-calculator`、既有 `--code-sandbox` 支持区分组织方式与计算工具的收益。`--case-order-seed` 只控制本地题序，不声称控制供应商采样。
- `cumulative_output_token_budget` / CLI `--cumulative-output-token-budget`：可选、默认关闭，原子预留根任务及所有后代的输出额度。已确认输出据实计量，未报告/未知 usage 保留请求前上限。输入另行汇总，不宣称总 token 或美元硬上限。已收到超限 usage 会如实计入，而不是截断费用记录。
- 数据库增量迁移 `0007_output_token_budget`：旧记录缺失预留时，从已有调用配置恢复；未知旧值无法恢复时按 65,536 保守占用。旧设置客户端省略新字段不会取消现有上限，显式 null 才会取消。后续审查、修订和收尾提示为 planning-only，不强制预留或保证模型采纳。
- 协议 v7 明确要求单一 JSON 对象、无多余顶层内容、字符串控制字符必须转义。两个 run06 格式失败被归纳为合成回归，不复制数学内容；坏格式继续严格拒绝。这是约束改进，尚无新付费试验能证明实际失败率下降。
- `scripts/compare_answerbench.py`：验证相同题面、模型、思考配置、预算、评分器和答案键；核对源码未变、无人资格、完整分母及重复批次，报告成对胜负、准确率差、按题目聚类 bootstrap 区间、单次重复的精确 McNemar 检验、无法评分敏感性范围及实际 token/时间。相同输出上限不会标为相同美元成本。

## 验证

- 初轮全后端 **543 通过、1 失败、0 跳过**：唯一失败为 `test_code_sandbox` 依赖宿主未配置镜像。修正测试隔离，显式移除该测试局部环境变量；未更改实际沙箱策略。原始记录 `benchmark-comparison-initial-2026-09-13.xml`。
- 最终受影响范围 **135 通过**：包含两种评测模式、基线、原 runner、评分、配对统计、父子共享预算、未知额度保留、旧设置兼容、旧 schema 升级及 4 项真实沙箱/API 验收。记录 `benchmark-comparison-final-2026-09-13.xml`。
- 最后补充的相关版本审查状态及比较模块回归 **10 通过**，记录 `benchmark-outcomes-final-2026-09-13.xml`。与上述计数有重叠，不累加为总测试数。
- Ruff 和 diff whitespace 检查通过。没有修改前端组件，本轮没有重复前端构建或浏览器全回归。

## 使用与限制

完整方案及命令见 [施工方案](../../施工方案/Agent与DeepSeek公平对照评测_2026-09-13.md)。下一步先准备未参与调参的题集、验证统一评分覆盖并确定新付费预算。旧四题仅作开发样本，不从已有单题失败推出 agent 整体优劣，也不以内部审查通过率代替外部证明盲评。

尚未实施美元硬上限、供应商精确输入 tokenizer 预留、官方 Gemini 付费评分、自动题内跨条件交错调度和外部证明盲评。公开模型是否见过公开题无法通过本地哈希证明。以上限制已在对照方案明确列出。
