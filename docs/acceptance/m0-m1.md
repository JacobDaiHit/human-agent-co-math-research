测试使用真实临时 SQLite，覆盖领域规则、状态 API、并发版本冲突、运行边界、回归缺陷、真实 HTTP/SSE 和迁移一致性。HTTP 测试启动临时回环服务并在结束后清理所属进程，不读取实际用户令牌。安装包已检查包含 API、运行时及迁移文件。

最终执行结果：**90 项测试通过，耗时 23.80 秒，2 条上游弃用提示；Ruff 检查及 21 个 Python 文件的格式检查全部通过。**

固定演示结果位于 [m0-m1-demo.json](m0-m1-demo.json)，七项检查均通过：旧证明受影响、旧运行被列出、替代证明保留、结论支持保留、迟到产物隔离、恢复读取新版、新 Attempt 独立记录。

演示中的数学正文和人工审查均为预先编写的测试材料。真实模型调用为 0，不把此结果计作模型发现数学成果。施工方案的“运行中修改引理”已验证状态和执行边界部分，尚待 M2/M3 以图形界面和真实模型完成完整验收。

## 本轮复审修复

1. 阻止未接入工具的人工录入伪造全范围精确计算证据；模型审查和形式检查亦不接受手工冒充。
2. 上下文角色异常输入返回 422；领域层也防御异常角色，避免数据库中一个坏对象令整个快照崩溃。
3. 正文编辑不会清空角色、来源等元数据；显式清空必须由请求给出。
4. 支持分析和审查列表只覆盖分支可见对象，保留这些对象的历史版本，不混入旁支独有对象。
5. 暂停/取消已生效后，迟到执行不会反向改写逻辑任务状态；新的执行和旧候选产物各自保留。
