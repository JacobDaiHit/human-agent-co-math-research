# 0001：先交付本地状态闭环

日期：2026-09-08。范围：M0—M1。

采用 Python 3.13、FastAPI、SQLAlchemy、Alembic 和 SQLite；Windows 项目独立 `.venv`，依赖锁定到 `uv.lock`。当前机器默认 Python 是旧版 Anaconda，因此首次安装显式指定已核对的 Python 3.13；这一观察不用于修改全局环境或其他项目。

当前没有前端和真实模型接入。以直接 HTTP 契约、确定性 FakeProvider 和独立领域测试验证版本、支持关系和执行边界，先消除后续 UI 与真实模型都会依赖的数据语义风险。

写命令使用 SQLite `BEGIN IMMEDIATE`，把版本、分支头、冲突候选、事件及幂等回执放进同一事务。快照以一致读事务计算支持关系，避免另外保存一份容易失效的“真值”字段；后续需要优化时再引入同事务失效标记及缓存。

审查采用与证据记录分离。当前人类录入接口禁止制造模型/形式化检查记录，并禁止将未接入执行器的手工精确计算声明为整份证明的机器证据。纯领域层保留未来受信任工具适配的证据类型。

对象版本 API 省略 payload 表示保留元数据，显式 `{}` 表示清空；上下文 role 校验为三种已知含义。分支快照只包含该分支可见对象及其历史版本，其他分支的新对象不进入当前支持分析。

Fake 运行具备租约与执行令牌，但没有外部收费请求。过期恢复能确认模拟任务不存在待对账外部操作；这一行为不得直接复用为未来真实提供方的无条件重试策略。临时的全局 2 并发限制后续替换为全局、项目、分支资源策略。

所有演示材料都是预置夹具，不能作为模型数学能力或项目创新性的证据。
