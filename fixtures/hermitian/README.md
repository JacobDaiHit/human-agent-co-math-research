# 排序特征值反例固定样例

来源：项目蓝图第 12 节与施工方案 §10.1。研究正文、失败路线及派生问题均预先编写，不能算作模型自主发现。调用 `POST /examples/hermitian` 时，内置工具实际执行有理系数矩阵运算；不接受任意代码或外部表达式。

原问题询问：实解析 Hermitian 矩阵族按大小排序后的特征值是否总在零点可微。固定矩阵为 `H(t)=[[0,t],[t,0]]`，实参数 `t`。

- 特征多项式：`λ²−t²`。固定向量 `(1,1)`、`(1,−1)` 对应 `t`、`−t`。
- 排序特征值：`−|t|`、`|t|`。左导数为 `(1,−1)`，右导数为 `(−1,1)`，二者均不可微。
- 独立派生问题：本例允许交换排序标签时，`t` 与 `−t` 是解析分支。一般矩阵族的结论仍待文献和独立论证。

计算记录标记 `actual_local_exact_calculation`，审查类型为 `exact_computation`、范围 `partial`。完整预写文字论证仍待人工审查；不会生成形式化通过标签或伪造用户已经采用。数值样本仅作辅助展示，不是不可微结论的依据。

实际请求返回的项目 ID、分支 ID、版本 ID 和计算 JSON 可用于后续导出；导出 ZIP 中的 `manifest.json` 保存准确版本与计算来源。测试见 `tests/integration/test_exports_recovery.py`。
